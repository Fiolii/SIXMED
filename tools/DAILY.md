# งานประจำวัน SIXMED: เพิ่มโจทย์และเกร็ดความรู้ใหม่ แล้ว push (ทุกวัน 16:30 · ครบทุกหัวข้อ หัวข้อละ ≥3 ข้อ)

เป้าหมาย: ให้ผู้ใช้เจอโจทย์/เนื้อหา **ใหม่จริง ไม่ซ้ำ** ทุกวัน สำหรับเตรียมสอบ กสพท (TPAT1 + A-Level) โดยเพิ่มแพ็กรายวันที่ `data/dq/days/YYYY-MM-DD.json` (และไฟล์ส่วนต่อ `YYYY-MM-DD_2.json` ถ้าเขียนเกิน 40 ข้อ)
แอปอ่านผ่าน `data/dq/manifest.json` + `data/dq/bundle-YYYY-MM.json` (สร้างโดย `tools/dq_build.mjs`) — **งานนี้แก้ได้เฉพาะ `data/dq/**` เท่านั้น ห้ามแตะโค้ดแอปหรือไฟล์อื่น**

## ขั้นตอน (ทำตามลำดับ ถ้าขั้นไหนล้มเหลวให้หยุดและรายงาน ห้าม push ของที่ยังไม่ผ่านตรวจ)
1. `cd` ไปโฟลเดอร์โปรเจกต์ (ที่มี `tools/DAILY.md`) · `git pull --ff-only origin main` (ถ้า pull ไม่ได้ให้หยุด)
2. ตรวจว่าโค้ดโหลดแพ็กมีอยู่ในรีโมตแล้ว: `git ls-files data/dq_load.js tools/dq_validate.mjs` ต้องมี 2 ไฟล์ ถ้าไม่มีให้หยุดและรายงาน
3. หาวันที่วันนี้ `date +%F` แล้วรัน `node tools/dq_validate.mjs --day <วันนี้>` — แสดงว่า**ทุกหัวข้อ**วันนี้มีโจทย์ใหม่กี่ข้อ ขาดอีกกี่ข้อ และไฟล์ถัดไปชื่ออะไร · ถ้าขึ้น "ครบทุกหัวข้อแล้ว" → จบงาน
4. `node tools/dq_validate.mjs --coverage` ดูหัวข้อที่โจทย์สะสมน้อยที่สุด แล้วให้หัวข้อเหล่านั้นได้โจทย์เกินขั้นต่ำ (ตอนเริ่มระบบ ภาษาไทย สังคมศึกษา และภาษาอังกฤษมีน้อยที่สุด)
5. **เป้าหมายต่อวัน: ทุกหัวข้อ (12 หัวข้อในตารางด้านล่าง) ได้โจทย์ใหม่อย่างน้อยหัวข้อละ 3 ข้อ รวมราว 36–40 ข้อ ในไฟล์เดียว** `data/dq/days/<วันนี้>.json` พร้อมเกร็ดความรู้ 3–5 รายการ (ถ้าเขียนเกิน 40 ข้อให้ใช้ไฟล์ `<วันนี้>_2.json` id เริ่ม `dq-YYYYMMDD-41` ไม่ต้องมีเกร็ด) · ทุกไฟล์ต้องมีทั้งกลุ่ม tpat1 และ alevel กลุ่มละ ≥3 ข้อ
6. เขียนเสร็จให้รัน `node tools/dq_validate.mjs data/dq/days/<ไฟล์>.json` ต้อง "ผ่านการตรวจ ✓" (exit 0) — ถ้าไม่ผ่านให้แก้แล้วตรวจใหม่ไม่เกิน 3 รอบ ถ้ายังไม่ผ่านให้ลบไฟล์ทิ้งและรายงาน · จากนั้นรัน `--day <วันนี้>` ยืนยัน
7. `node tools/dq_build.mjs` (สร้าง bundle + manifest) · ถ้าขนาดไฟล์ `data/dq/bundle-*.json` รวมเกิน 6 MB ให้หยุดและรายงานผู้ใช้
8. `git add data/dq` เท่านั้น (ห้าม `git add -A` / `git add .`) → `git status --short` ต้องเห็นเฉพาะไฟล์ใน `data/dq/` ที่ staged
9. `git commit -m "Daily content YYYY-MM-DD: N questions, M notes"` ปิดท้ายข้อความด้วยบรรทัด `Co-Authored-By: Claude <noreply@anthropic.com>`
10. `git push origin main` · รายงานสั้น ๆ: วันที่ จำนวนข้อต่อหัวข้อ และผลการตรวจ

## ข้อกำหนดของแพ็ก
ไฟล์: `{ "date": "YYYY-MM-DD", "questions": [...], "notes": [...] }`
- **โจทย์ราว 36–40 ข้อ/วัน** ครบทุกหัวข้อหัวข้อละ ≥3 ข้อ: TPAT1 3 หัวข้อ (เชาวน์ปัญญา · จริยธรรมทางการแพทย์ · ความคิดเชื่อมโยง) + A-Level คณิต 3 หัวข้อ + ฟิสิกส์ + เคมี + ชีววิทยา + ภาษาไทย + สังคมศึกษา + ภาษาอังกฤษ · A-Level ใส่แบบตอบเป็นตัวเลข (`type: "num"`) รวมวันละ ≥5 ข้อ · ระดับ ง่าย 20% / กลาง 45% / ยาก 35% (`diff` 1/2/3) · **ห้ามลดคุณภาพเพื่อให้ได้จำนวน** — ถ้าข้อไหนไม่แน่ใจเฉลย ให้ตัดทิ้งแล้วเขียนข้อใหม่ทดแทน
- เนื้อหาเน้นบริบทการแพทย์/สุขภาพเมื่อทำได้ (เช่น ฟิสิกส์ของการไหลของเลือด อัลตราซาวด์ เคมีของยาและบัฟเฟอร์ในร่างกาย) แต่ต้องอยู่ในขอบเขตหลักสูตร ม.ปลาย
- **TPAT1 แต่ละส่วน**
  - เชาวน์ปัญญา: อนุกรม อุปมาอุปไมย ตรรกะ/การสรุปความ เซต ปฏิทิน รหัส โจทย์ตัวเลขเชิงเหตุผล
  - จริยธรรมทางการแพทย์: สถานการณ์ให้เลือกการกระทำที่เหมาะสมที่สุด (การรักษาความลับ ความยินยอม การบอกความจริง ผลประโยชน์ทับซ้อน ความปลอดภัยผู้ป่วย การคัดแยกผู้ป่วย ความเป็นมืออาชีพ) ทุกตัวเลือกต้องฟังดูเป็นไปได้ ไม่ใช่ข้อผิดชัดเจน
  - ความคิดเชื่อมโยง: บทความสั้นใน `passage` (ใช้บทความเดียวกันได้หลายข้อ) แล้วถามความสัมพันธ์ระหว่างข้อความ (1) กับ (2) ใช้ชุดตัวเลือกความยาวใกล้เคียงกัน เช่น `["(1) เป็นสาเหตุที่ทำให้เกิด (2) ตามบทความ", "(2) เป็นสาเหตุที่ทำให้เกิด (1) ตามบทความ", "(1) กับ (2) ขัดแย้งกันตามที่บทความระบุ", "(1) กับ (2) เกี่ยวข้องกัน แต่ไม่ใช่เหตุและผล", "(1) กับ (2) ไม่เกี่ยวข้องกันตามบทความ"]` · เขียนข้อความในโจทย์แต่ละข้อให้ต่างกันจริง (ตัวตรวจจับโจทย์ที่คล้ายกันเกิน 55%)
- **A-Level ภาษาไทย**: การสะกดคำ ระดับภาษา ประโยคกำกวม/บกพร่อง สำนวน ภาพพจน์ การเรียงข้อความ การอ่านจับใจความและจุดประสงค์ผู้เขียน (ใช้ `passage`) · ข้อหลักภาษาที่ตำราอธิบายต่างกันหรือไม่แน่ใจ ให้ตัดทิ้ง
- **A-Level สังคมศึกษา**: ศาสนา หน้าที่พลเมืองและกฎหมาย เศรษฐศาสตร์ ประวัติศาสตร์ ภูมิศาสตร์ · ใช้เฉพาะข้อเท็จจริงที่ยืนยันได้ ห้ามข้อการเมืองร่วมสมัยที่เป็นความเห็น
- **A-Level ภาษาอังกฤษ**: บทสนทนา คำศัพท์ในบริบท ไวยากรณ์ และการอ่าน (ใช้ `passage` ภาษาอังกฤษ) · โจทย์ ตัวเลือก และ `exp`/`why` เขียนเป็นภาษาอังกฤษ
- **เกร็ดความรู้ 3–5 รายการ/วัน** (`notes` ในไฟล์ส่วนที่ 1 เท่านั้น): วิธีคิดลัด กับดักที่พบบ่อย หรือแนวคิดที่ต่อยอดจากโจทย์วันนี้ ยาว 120–900 ตัวอักษร
- **เขียนเอง ห้ามคัดลอกข้อสอบจริง/หนังสือเรียน/เว็บใด** (ลิขสิทธิ์) — ค้นเว็บเพื่อศึกษาขอบเขตเนื้อหาและสไตล์ได้ แล้วเขียนโจทย์ใหม่ด้วยตัวเลข/บริบท/ตัวเลือกของตัวเอง
- **ทุกข้อต้องมีเฉลยที่ถูกต้องข้อเดียวชัดเจน** ข้อที่ต้องคำนวณให้ **รันโค้ด (node) ตรวจคำตอบจริงก่อนเขียนลงไฟล์** ห้ามเดา · ตัวเลือกผิดมาจากข้อผิดพลาดยอดฮิตที่ฟังดูสมเหตุสมผล
- **ห้ามให้ข้อถูกเดาได้จากความยาว**: ตัวเลือกทุกข้อต้องยาว/ละเอียดใกล้เคียงกัน ข้อถูกควรเป็นข้อที่ยาวที่สุดไม่เกิน ~25% ของโจทย์ และยาวไม่เกิน 1.2 เท่าของค่าเฉลี่ยข้อผิด (ตัวตรวจจะไม่ผ่านถ้าเกิน)
- ไม่ทำโจทย์ที่ต้องมีรูปภาพ (ห้ามมี `fig`) · ตัวห้อย/ตัวยกใช้ได้ เช่น `H₂O`, `x²` · ข้อความล้วน ห้ามมี HTML

### รูปแบบโจทย์ปรนัย (ตัวเลือก 5 ข้อ)
```json
{ "id": "dq-20261117-01", "group": "tpat1", "subject": "TPAT1", "topic": "เชาวน์ปัญญา", "diff": 2,
  "q": "โจทย์...", "c": ["ก", "ข", "ค", "ง", "จ"], "a": 2,
  "exp": "วิธีทำ/เหตุผลของข้อที่ถูก (หลายบรรทัดได้ ใช้ \n)",
  "why": ["ข้อ ก ผิดเพราะ...", "ข้อ ข ผิดเพราะ...", "", "ข้อ ง ผิดเพราะ...", "ข้อ จ ผิดเพราะ..."],
  "tip": "เคล็ดลับสั้น ๆ (ไม่บังคับ)", "passage": "บทอ่าน (ไม่บังคับ)" }
```
- `id` = `dq-YYYYMMDD-NN` (ไฟล์แรกเริ่ม 01 · ไฟล์ `_2` เริ่ม 41) · `why` ต้องมี 5 ช่อง ช่องของข้อที่ถูกเป็น `""` · `a` = ตำแหน่งข้อที่ถูก 0–4 · ตัวเลือกที่เป็นตัวเลขล้วนให้เรียงน้อย→มาก
### รูปแบบโจทย์ตอบเป็นตัวเลข (A-Level)
```json
{ "id": "dq-20261117-30", "group": "alevel", "subject": "ฟิสิกส์", "topic": "ฟิสิกส์", "diff": 2, "type": "num",
  "q": "โจทย์...", "ans": 4, "tol": 0.01, "unit": "s", "exp": "วิธีทำ...", "wrong": [[2, "คำตอบผิดที่พบบ่อย ได้มาเพราะ..."]] }
```
### เกร็ดความรู้
```json
{ "id": "dn-20261117-01", "title": "หัวข้อสั้น ๆ", "topic": "ชีววิทยา", "body": "เนื้อหา...", "link": "https://... (ไม่บังคับ)" }
```
### ชื่อหัวข้อที่ใช้ได้ (ต้องตรงตัว ดูตัวเลขล่าสุดด้วย `--coverage`)
| group | subject | topic |
|---|---|---|
| tpat1 | TPAT1 | เชาวน์ปัญญา · จริยธรรมทางการแพทย์ · ความคิดเชื่อมโยง |
| alevel | คณิต | คณิต: พีชคณิตและฟังก์ชัน · คณิต: ตรีโกณ เวกเตอร์ เมทริกซ์ · คณิต: แคลคูลัสและความน่าจะเป็น |
| alevel | ฟิสิกส์ / เคมี / ชีววิทยา | ฟิสิกส์ · เคมี · ชีววิทยา (subject กับ topic ใช้ชื่อเดียวกัน) |
| alevel | ภาษาไทย / สังคมศึกษา / ภาษาอังกฤษ | ภาษาไทย · สังคมศึกษา · ภาษาอังกฤษ (subject กับ topic ใช้ชื่อเดียวกัน) |

## ความปลอดภัยของงาน
- แก้/commit/push เฉพาะ `data/dq/**` · ไม่ใช้ `--force` · ไม่แก้ประวัติ git · ไม่ push ถ้า validator ไม่ผ่าน
- ถ้า `git status` มีไฟล์อื่นที่ผู้ใช้แก้ค้างอยู่ ให้ปล่อยไว้ ห้าม stage/commit/ลบ
- ถ้าเกิดข้อสงสัยว่าเนื้อหาผิดวิชาการ ให้ตัดข้อนั้นออก (ดีกว่าใส่ข้อที่เฉลยผิด)
- `--lengths` อาจแจ้งข้อเก่าในคลังหลัก (เช่น `t1-iq04`) ซึ่งไม่ใช่งานนี้ ไม่ต้องแก้และไม่ใช่เหตุให้หยุด
